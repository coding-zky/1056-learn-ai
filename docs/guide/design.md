# 设计理念

AI Chat UI 是基于 **Vue 3 + TypeScript** 的 AI 聊天界面组件库，核心卖点是 **Agent 过程可视化**——让用户看到 Agent 每一步在干什么、调了什么工具、当前走到哪、哪里可以插手，而不只是看到最终回复。走「前期开源、后期商业化」的路径。

## 五个目标

1. **后端无关**：组件不绑定任何模型 / 后端，切换数据源不改组件代码。
2. **Agent 过程可视化**：思考、工具调用、步骤状态、审批点全程可见、可干预（差异化尖刀）。
3. **Headless**：逻辑（composable）与样式（UI 组件）分层，用户可只拿逻辑自己写界面，也可整体换主题。
4. **按需安装**：想用哪块装哪块，不打全家桶。
5. **流式优先**：所有生成类组件原生支持 token 流、停止、错误、重试。

## 差异化

React 侧已成熟：assistant-ui、AI Elements、CopilotKit 等；**Vue 侧存在空档**，尤其「Agent 过程可视化」在 Vue 侧几乎空白——这是本项目的差异化切口。

## 非目标

- 不是 agent 后端框架：不管理编排、记忆、工具调度、RAG，组件只消费输出。
- 不是完整应用：不做登录、鉴权、数据库、部署。
- 不是某一家模型的 SDK 封装：不重复造 Vercel AI SDK 已有的能力。
