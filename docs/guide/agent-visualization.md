# Agent 过程可视化

这是本项目的差异化尖刀：让用户看到 Agent 每一步在干什么，而不只是最终回复。

## 可见链路

事件流里的四类事件构成「思考 → 工具调用 → 步骤 → 审批」的可见链路：

- `thinking` — 思考过程；
- `tool-call-start` / `tool-call-end` — 工具调用的开始与结束（名称、参数、耗时、成败）；
- `step-status` — 步骤状态（排队 → 执行中 → 完成 / 失败 / 中断）；
- `approval-request` — 请求审批（同意 / 拒绝 / 改参数重跑）。

## 关键交互

1. **时间线默认折叠成摘要 + 自动滚动跟随**：每步显示「名称 + 状态 + 耗时」，点开看详情；运行中自动滚底跟随，用户上翻即暂停。
2. **审批点永远展开**：审批是可干预的底线，任何时刻都不折叠。
3. **面板无关**：同一套过程数据模型，两种视图——独立 `AgentPanel`（旗舰）+ 内嵌流（轻量）。

## 组件规划

| 组件               | 说明                                       |
| ------------------ | ------------------------------------------ |
| `ThinkingState`    | 思考 / 工作状态条                          |
| `ToolCallCard`     | 单个工具调用卡：参数、耗时、返回摘要、成败 |
| `AgentRunTimeline` | 步骤时间线                                 |
| `ApprovalGate`     | 审批点：同意 / 拒绝 / 改参数               |
| `AgentPanel`       | 独立时间线面板（旗舰形态）                 |

> 这些组件在 Phase 2 实现，当前仓库尚未提供。
