# 组件总览

当前可用的组件：

| 组件                               | 状态    | 说明                                 |
| ---------------------------------- | ------- | ------------------------------------ |
| [Button 按钮](/component/button)   | ✅ 可用 | 常用的操作按钮                       |
| [Chat 聊天容器](/component/chat)   | ✅ 可用 | 接入 `ChatProvider` 事件流的聊天容器 |
| [Message 消息](/component/message) | ✅ 可用 | 单条文本消息                         |

更多组件（`PromptInput`、`StreamingMarkdown`、Agent 可视化组件等）在后续 Phase 逐步补齐，见[设计理念](/guide/design)。
